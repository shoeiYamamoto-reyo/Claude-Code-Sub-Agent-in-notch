# アプリのアイコン（仮）

- 2026-11-07 に、手元で使うときに見分けやすいよう仮のアイコンを入れた。正式なものは公開準備（ROADMAP 5-9）で決める。
- どれもノッチのキャラ（`docs/design/character.md` の体と目）を、macOS のアイコンの枠（1024 中 824 × 824、角丸 185）に載せたもの。
  - `icon_A.svg`（採用中）: 黒い角丸に白いキャラ、待機中の点の目。ノッチの黒に載ったキャラのいつもの見た目。
  - `icon_B.svg`: 明るい背景の上部にノッチ、その下にキャラ（承認待ちの大きな目）。
  - `icon_C.svg`: 紫の背景に完了の「^ ^」の目。
- 書き出し: SVG を 1024 × 1024 の PNG にし（ブラウザや `rsvg-convert` など）、16〜512 pt の 1x / 2x に縮小して `App/Resources/Assets.xcassets/AppIcon.appiconset/` に置く。ファイル名は `Contents.json` のとおり。
