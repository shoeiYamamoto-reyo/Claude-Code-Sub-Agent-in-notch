# サブエージェントのキャラクター一覧（ROADMAP 4-3）

- ステータス: 試作（2026-10-27）。触ってみて見直す。
- 「エージェント」タブで、サブエージェント定義をノッチのキャラ（`character.md`）と同じ形で並べる。
- 後で、実行中のセッションのツリー（F3-2）でも同じキャラ・同じ色を使う予定。

## 色
- 体の色は frontmatter の `color`。Claude Code の色名をそのまま塗ると目（`#2B2230`）が見えにくいので、淡い色に置き換える。
- **白（`#FBFAF6`）はノッチのキャラだけ**に使う。一覧では使わない。

| `color` | 体 | 底の陰 |
| --- | --- | --- |
| red | `#F4A3A3` | `#DC8A8A` |
| blue | `#9DC3F5` | `#84A9DA` |
| green | `#A8DDA8` | `#8EC48E` |
| yellow | `#F6E08E` | `#DDC674` |
| purple | `#C9B0F2` | `#AF96D8` |
| orange | `#F7BE8A` | `#DEA471` |
| pink | `#F5B3D6` | `#DB99BC` |
| cyan | `#99E0E3` | `#7FC6C9` |
| 指定なし・知らない値 | `#CFCAC2` | `#B6B1A9` |
| 読めない定義 | `#8C8986` | `#75726F` |

## 表示
- 見出し（ユーザー共通、プロジェクトごと）の下に、1 体 56 × 40 pt のキャラと名前を格子に並べる。最後に点線の輪郭のキャラ「新規」を置き、押すと作成画面を開く。
- 読めない定義は濃い灰色で目を「> <」にし、名前（ファイル名）をオレンジにする。押しても開かない（右クリックの「Finder で表示」から直す）。
- 同じ名前の別の定義に隠されているものは薄く（不透明度 0.55）する。
- マウスを乗せたキャラは待機中の動き（呼吸・まばたき、12 fps）をし、一覧の上の欄に name・model・tools・description を出す。押すと編集、右クリックで「編集…」「Finder で表示」。
- それ以外のキャラは止めた絵にする（何体並んでも待機中に描き直さない）。「視差効果を減らす」がオンなら、乗せても動かさない。

## 実装メモ
- 色は `Sources/AgentKit/Agents/AgentAppearance.swift`、一覧は `App/Sources/Agents/AgentListView.swift`。
- 絵は `CharacterCanvas` に `CharacterPalette` を渡して描く（ノッチは `CharacterSpec.notchPalette`）。
