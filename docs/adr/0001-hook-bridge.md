# ADR-0001: Claude Code との連携は hooks + 中継 CLI + Unix ソケットで行う

- ステータス: 提案中
- 日付: 2026-10-25

## 背景
アプリは Claude Code の実行状況をリアルタイムに受け取り、権限リクエストにはユーザーの判断を返す必要がある。

## 選択肢
1. **hooks から中継 CLI を呼び、Unix ソケットでアプリに転送する**（coucou と同じ方式）
2. トランスクリプト（`~/.claude/projects/*/*.jsonl`）をファイル監視する
3. アプリから `claude -p --output-format stream-json` で Claude Code を起動して管理する

## 決定
1 を採用する。2 はサブエージェントの詳細表示などの補助に使う。3 は「ノッチからエージェントを起動する」機能が必要になった時点で別途検討する。

## 理由
- 承認への応答（双方向）ができるのは hooks だけ。
- 既存のターミナル運用を変えずに使える。
- イベント駆動なので非表示時の CPU 使用率 0 % を狙える。

## 影響
- `~/.claude/settings.json` に hooks を追加する必要がある → バックアップ・差分表示・確認付きのインストーラを用意する。
- 中継 CLI は「アプリが居なければ即終了」を厳守する。接続タイムアウトとテストを必須にする。
